# 방명록 구글시트 연결

방문자가 쓴 메시지를 구글시트에 저장하고, 앱이 10초마다 새로 불러온다.

## 1. 시트와 스크립트 만들기
1. 구글 드라이브에서 새 **구글 스프레드시트**를 만든다 (이름 자유).
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 기본 코드를 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣은 뒤 저장한다.
4. 위쪽 함수 선택에서 `setup` 을 골라 **실행**한다. 권한 요청이 나오면 허용한다.
   (`messages` 시트와 머리글이 만들어진다.)

## 2. 웹 앱으로 배포
1. **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
3. 배포 후 나오는 **웹 앱 URL(`.../exec`로 끝남)** 을 복사한다.
4. 브라우저에서 그 URL을 열어 `{"ok":true,"messages":[]}` 가 보이면 정상이다.

## 3. 앱에 연결
- 내 컴퓨터: `app/.env.local` 파일에 한 줄 추가 후 개발 서버를 다시 켠다.
  `VITE_GUESTBOOK_URL=복사한주소`
- Vercel: 프로젝트 **Settings → Environment Variables** 에 `VITE_GUESTBOOK_URL` 을 추가하고 **다시 배포(Redeploy)** 한다.
  (빌드 때 값이 들어가므로 추가만 하고 재배포하지 않으면 적용되지 않는다.)
- 값이 비어 있으면 이 브라우저에만 저장하는 데모 모드로 동작한다.

## 운영
- 새 글은 바로 공개된다. 숨기려면 시트에서 그 줄의 **visible 체크를 끈다** (다음 불러오기 10초 안에 사라짐). 줄을 지워도 된다.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 편집 → 새 버전** 으로 올려야 반영된다 (URL은 그대로).
- 주소를 아는 사람은 누구나 글을 쓸 수 있다. 방어는 길이 100자, 같은 방문자 3초 간격, 자동 입력 차단, 중복 요청 무시까지다.
